# Piloto Mobile: NEXO Operacional

## Objetivo do Piloto
Validar o uso prático do aplicativo NEXO Operacional em ambiente real de campo com funcionários das lojas piloto. O foco está na estabilidade, usabilidade e segurança dos dados operacionais.

## Duração Recomendada
- **Fase 1 (Interna):** 3 a 5 dias (apenas gestores e TI).
- **Fase 2 (Piloto Fechado):** 10 a 15 dias (equipe operacional selecionada).

## Perfis Participantes
- Gerente
- Vendedor
- Técnico (Medição)
- Almoxarife
- Logístico (Entrega)
- Montador
- Pós-venda
- Financeiro

## Pré-requisitos
1. Usuário ativo no sistema NEXO Web com perfil e loja configurados.
2. Smartphone Android (8.0+) ou iOS (13+).
3. Conexão com internet (mínimo 4G) para sincronização inicial.

## Checklist Antes de Iniciar
- [ ] Usuário possui e-mail e senha de acesso.
- [ ] Usuário está vinculado à loja correta.
- [ ] Perfil de acesso (Role) está definido no banco de dados.
- [ ] Tokens de push estão habilitados para a loja.

## Como Instalar o App
1. **Android:** Baixar o arquivo APK fornecido pela equipe técnica ou via link do Firebase App Distribution.
2. **iOS:** Aceitar o convite no e-mail para o TestFlight e instalar o app NEXO Operacional.

## Roteiros de Teste por Perfil
Consulte o arquivo `CHECKLIST_MOBILE_PERFIS.md` para o roteiro detalhado de cada função.

## Como Reportar Problemas
Utilize a função **"Enviar Feedback"** dentro do aplicativo, localizada na tela inicial ou no perfil do usuário. Para erros críticos (app não abre), reporte via canal oficial de suporte (WhatsApp/E-mail).

## Critérios de Sucesso
- 90% dos usuários conseguem realizar login sem auxílio.
- Notificações de tarefas chegam em até 2 minutos após a criação.
- Chat interno utilizado para comunicação em pelo menos 5 contratos.
- Feedbacks registrados e categorizados sem perda de dados.
