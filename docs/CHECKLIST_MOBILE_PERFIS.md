# Checklists por Perfil - NEXO Mobile

## 🛡️ Gerente / Admin
- [ ] Visualizar dashboard inicial com resumo de atividades da loja.
- [ ] Acessar lista de comunicados e marcar como lido.
- [ ] Abrir qualquer conversa de chat de contrato da sua loja.
- [ ] Verificar se as tarefas de todos os membros da equipe aparecem na agenda (visão ampla).

## 🤝 Vendedor
- [ ] Visualizar seus contratos ativos.
- [ ] Acompanhar status de entregas e montagens dos seus clientes.
- [ ] Receber notificação de contrato assinado ou pagamento confirmado.
- [ ] **Não deve:** Acessar custos financeiros detalhados ou movimentação de estoque.

## 📏 Técnico / Medidor
- [ ] Acessar agenda de medições do dia.
- [ ] Registrar início de medição no local.
- [ ] Anexar fotos/evidências da medição.
- [ ] Registrar conclusão da tarefa.

## 📦 Almoxarife
- [ ] Visualizar lista de separação de materiais para o dia.
- [ ] Validar itens em estoque via app.
- [ ] Registrar saída de material para logística.

## 🚚 Logístico / Entregas
- [ ] Visualizar rota de entregas.
- [ ] Iniciar jornada de entrega.
- [ ] Registrar entrega realizada com foto do comprovante.
- [ ] Coletar assinatura digital do cliente no recebimento.

## 🔨 Montador
- [ ] Acessar agenda de montagens.
- [ ] Visualizar projeto/detalhes do contrato.
- [ ] Registrar progresso da montagem (Início, Pausa, Fim).
- [ ] Abrir chamado de assistência (pós-venda) se necessário.

## 💰 Financeiro
- [ ] Visualizar notificações de pagamentos pendentes.
- [ ] Verificar status de documentos financeiros emitidos.
- [ ] **Não deve:** Alterar dados de estoque ou roteiros de logística.
