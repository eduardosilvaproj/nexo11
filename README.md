# Nexus Planejados

ERP completo para lojas de móveis planejados.

## Módulos

- **Comercial** - Leads, contratos, propostas
- **Engenharia** - Medições, projetos técnicos
- **Produção** - Ordens de fabricação
- **Logística** - Entregas e montagem
- **Pós-Venda** - NPS, assistências
- **Financeiro** - DRE, comissões, fluxo de caixa
- **Analytics** - BI e dashboards
- **Capture** - Importação de plantas e geração SKP para Promob
- **Onboarding** - Wizard de primeiro acesso
- **Mobile** - Apps para vendedor, medidor, conferente, montador, entregador

## Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Supabase
- Three.js (viewer 3D)
